# 🤖 개인 자비스(Jarvis) 시스템 — 아이디어 메모

> 작성: 2026-08-30 · 상태: **아이디어 캡처만. 세부 플랜 미착수**
> 브랜치: `claude/personal-jarvis-system-5orlq7`
> 지금은 급한 일(시즌 운영) 먼저 처리하고, 그다음에 이 문서 열어서 플랜부터 짠다.

---

## 한 줄 정의

> "내가 잘되게 하고, 돈도 잘 벌게 하고, 스케줄·미팅 준비까지 알아서 굴려주는 나만의 비서."

사람이 시켜야 움직이는 챗봇이 아니라, **먼저 물어보고 먼저 준비해두는 상시 비서**가 목표.

---

## 원하는 것 (원문 그대로 남김)

- 내가 **잘되게** 한다 → 목표/커리어/사업 방향을 계속 트래킹하고 리마인드
- **돈도 잘 벌게** 한다 → 매출·정산·기회(제안, 지원사업, 협찬 등) 관리
- **스케줄 관리**
- **미팅 준비** (사전 브리프, 자료, 팔로업)
- **등등** — 알아서 관리

---

## 큰 덩어리 4개 (나중에 각각 쪼갤 것)

### 1. 스케줄 · 캘린더
- Google Calendar 이미 연동 경험 있음 (이 레포 `src/lib/google-calendar.ts` — API v3 + API Key)
- 아침 브리프 / 하루 전 리마인드 / 일정 충돌 감지
- 이동시간·장소 고려 (양양–서울 이동 잦음)

### 2. 미팅
- 미팅 전: 상대방/회사 리서치, 지난 대화 요약, 이번에 꺼낼 안건 3개
- 미팅 후: 노트 → 액션아이템 → 캘린더/할일로 자동 등록
- 팔로업 메일 초안까지

### 3. 돈 (수익 파이프라인)
- 들어올 돈 / 나갈 돈 / 미수금 트래킹
- 기회 파이프라인: 제안 보낸 곳, 답 기다리는 곳, 데드라인 있는 지원사업·공모
- 정기 리포트 (주간/월간 — 이번 달 얼마 벌었고 뭐가 밀렸는지)

### 4. 나 (성장 · 목표)
- 분기/연간 목표 → 주간 단위로 쪼개서 체크
- "이번 주에 목표에 실제로 기여한 일이 뭐였나" 회고
- 놓치고 있는 것 먼저 지적해주기 (잔소리 담당)

---

## 시스템 구조 방향 (가설, 확정 아님)

- **두뇌**: Claude (Agent SDK / Claude Code 스케줄 트리거)
- **기억**: 어딘가에 상태를 남겨야 함 — Supabase(이미 쓰는 중) 또는 레포 내 마크다운
- **눈·손**: MCP 커넥터 — Google Calendar / Drive / Gmail / GitHub 이미 붙어 있음
- **입력 채널**: 카톡? 텔레그램? 웹 대시보드? 그냥 Claude 앱? → 미정
- **작동 방식**: 크론(Routine)으로 자동 실행 + 필요할 때 대화로 개입

---

## 먼저 정해야 할 것 (플랜 짤 때 답할 질문)

1. **어디서 말 걸 건가** — 채널 하나 정해야 나머지가 정해진다
2. **어디까지 자동으로 하게 둘 건가** — 초안까지만? 발송까지? (돈·외부 발송은 무조건 확인 받게)
3. **기억을 어디에 둘 건가** — Supabase vs 마크다운 레포 vs 노션
4. **레포를 분리할 건가** — ysa-website 안에 두는 건 아닌 듯. `jarvis` 별도 레포 권장
5. **1번으로 만들 기능 하나** — 전부 만들려다 아무것도 안 되는 게 제일 흔한 실패

## 추천 시작점 (내 의견)

아침 브리프 하나부터. 매일 아침 캘린더 + 오늘 미팅 브리프 + 이번 주 돈 관련 데드라인을
한 장으로 보내주는 것. 이게 돌아가면 위 4개 덩어리의 배관이 전부 깔린 셈이라
나머지는 거기에 얹기만 하면 된다.
